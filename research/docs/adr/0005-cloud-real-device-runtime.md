# Android 运行目标优先云真机

2026-09-23 第二轮架构访谈中，用户选择云真机作为首期 Android 运行目标，取代默认模拟器的原建议。这里的云真机是通过远程服务访问的物理 Android 设备；开发与构建仍在开发执行节点进行，安装、应用交互和设备测试发生在云真机上。

因此架构需要独立的设备服务适配边界，表达设备分配与释放、应用安装启动、画面与输入、测试执行及结果回收。不能默认云真机供应商同时提供通用开发机桌面，也不能把只提供截图或临时人工体验的服务当作满足全部接口的长期开发环境。

第三轮用户进一步确定使用自己部署或开发的云真机测试平台，需要完成开源底座与自研边界选型；商业公有云真机不作为首期默认方案。具体底座仍需依据实际集成验证选定，见技术架构中的设备平台选型。

接入需核对持续设备租用、远程控制、测试接口及网络条件；优先云真机不等于任意平台均已被验证适配。预览设备与系统测试设备分开占用，平台业务数据不依赖设备底座内部的数据结构。

## RED / GREEN 记录

1. 无 runId 发送旧接口返回 400（RED）；后端内建轮次、session 查询和串行锁后通过（GREEN）。
2. 外部工具没有 waiting_tool 状态而超时（RED）；唯一外部调用 ID、持久化待办和结果回传后通过（GREEN）。
3. /stop 返回 404（RED）；按 session 停止并等待结束后通过（GREEN）。
4. SIGKILL 重启仍显示 waiting_tool（RED）；首次访问标记 interrupted 后通过（GREEN）。
5. 旧网关 resume 无法发起澄清（RED）；改为一次发送加 session 查询后澄清/自动开发通过（GREEN）。
6. 旧 llm_runs 最近结果查询 404（RED）；保留原表并懒迁移后通过（GREEN）。
7. 真实 HTTP 转发后主动丢弃聊天/工具结果响应，验证查询恢复、不重复发送（回归通过）。

8. 审查发现连接保持但无响应会导致停止永久等待；真实代理挂起响应测试先失败（busy 持续），加入覆盖请求及响应体的 5 秒超时后通过。

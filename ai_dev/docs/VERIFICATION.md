## 已确认测试边界

用户确认四个边界：网关 HTTP/SSE、执行服务接口、文件/预览接口、浏览器用户操作。测试通过这些公开接口观测行为；数据库只用于应用实际运行，不通过 SQL 查询作为业务断言。确定性测试只替代外部模型 HTTP，保留真实 Pi SDK、Git、MySQL 和两个应用服务。

## 验证结果

- `bun test`：9 项测试通过，41 个断言，0 失败。
- `bun run build`：Vue/Vite 构建通过。
- `bun run smoke:pi`：真实模型写文件和 Shell 工具通过；立即停止请求在 5 秒内返回，并能继续对话。
- `bun run smoke:flow`：真实模型经网关修改需求代码、保存澄清后说明，预览返回修改后的 HTML。
- `bun run smoke:ui`：Chrome 中创建需求、进入详情、新会话、发送消息、刷新、收起/展开与真实 iframe 预览通过；390px 宽度无横向溢出，控制台无错误/警告；页面截图已人工查看。
- 数据迁移在独立空数据库连续运行两次通过。
- 执行服务 `SIGKILL` 后重启：旧轮次显示中断；继续时没有自动重放旧请求。
- 多会话真实 Pi 工具执行：两个会话可同时向同一工作区写入不同文件，对话记录互不混入。

## 当前实现取舍

- Pi 可恢复检查点在轮次结束保存，轮次进行中保留展示状态。尚未实现每个完整工具消息的原生检查点；突然退出可能丢失当前轮次的模型上下文，需要先检查磁盘再继续。
- 重复轮次 ID 去重限定于存活执行实例；跨进程恢复依靠网关保留轮次记录、不自动重放，不提供跨节点 exactly-once 执行保证。
- 新建 worktree 后若数据库写入失败，可能遗留尚未关联的目录；不会自动删除它或覆盖原仓库。首期没有后台清理器。
- 文件和差异展示单文件限制 2MB；静态预览不是任意框架的开发服务器代理。
- Shell 有本机用户权限，文件工具检查和本地来源校验不能替代系统沙箱，也不能保证并发 Git/Shell 无冲突。
- 本次验证使用临时数据库；日常使用需配置持久 MySQL，不能将临时目录当作长期数据存储。

这些限制不以模拟成功掩盖；其他业务模块、云端接入、多人权限和设备预览均未实现。

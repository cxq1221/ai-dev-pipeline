# 需求开发工程

本上下文描述围绕需求开展会话、组织执行并由 AI 完成代码开发的核心语言。

## Language

**需求**：
用户希望解决的一项业务问题，是需求说明、会话、代码成果和运行预览的共同归属。
_Avoid_: 产品版本、聊天消息

**需求会话**：
围绕同一需求的一组连续交流，具有独立的对话上下文；同一需求的多个会话共享需求说明、代码和预览。
_Avoid_: 独立需求、独占工作区

**澄清后的需求**：
结合原始需求与对话形成的目标、范围和行为要求，是后续开发、测试和产品发布的业务依据。
_Avoid_: 对话流水、开发日志

**开发执行**：
会话中的一次有明确输入、过程和结果的 Agent 工作，可以包含多轮模型思考和工具操作。
_Avoid_: 一次模型请求、一条消息

**Agent 统一调度网关**：
关联需求会话、执行上下文、能力调度、任务状态与成果的统一协调入口。
_Avoid_: LLM 网关、另一个编码 Agent

**会话执行 Agent**：
围绕一个需求会话理解意图、形成计划并执行开发的自主执行者。
_Avoid_: 全需求唯一可写 Agent、SDK Runner

**共享工作区**：
一项需求持续维护的共同代码现场；各会话共享其中的代码和预览，同时保留各自的对话上下文。
_Avoid_: 每会话独立代码副本、临时聊天目录

**会话上下文检查点**：
某一时刻可供执行者恢复理解与继续对话的会话状态，包含当时保留的消息及工具结果；不代表代码现场已被快照或回滚。
_Avoid_: 前端聊天展示、工作区备份

**需求分支**：
承载同一需求代码修改的分支，是本期开发成果的交付位置。
_Avoid_: 产品版本、主干分支

**运行预览**：
用户和 AI 查看并操作运行中应用或开发桌面的反馈场景。
_Avoid_: 系统测试通过证明、人工验收

**SDK Runner**：
随目标应用或 SDK 运行、接收受限操作并返回状态的执行者。
_Avoid_: 编码 Agent、自主规划 Agent

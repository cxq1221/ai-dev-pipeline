# Forge AI 交付工作台原型

面向研发交付流程的单页交互原型，覆盖统一需求池、需求开发、提交记录、仓库配置、版本工作台、制品管理、测试执行与测试资源管理。

## 在线体验

GitHub Pages 启用后，可从仓库主页提供的站点链接进入。

## 本地运行

直接打开 `ai-dev-pipeline-prototype.html`，或在本目录运行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765/`。

## 说明

当前版本为无后端的交互原型。页面中的 AI、Jira、Git、构建、测试、设备连接和发布数据均为模拟数据；刷新页面会恢复初始状态，不会连接或修改真实系统。

开发测试针对单次代码修改；版本系统测试针对候选包，两类结果不互相替代。测试资源中的“测试用例集”维护 MeterSphere 项目用例链接；创建版本可绑定多个用例集，发起系统测试时必须选择至少一个。执行记录保存当次用例集快照，不受后续配置编辑影响。

当前不导入或执行真实 MeterSphere 用例。新系统测试报告采用用例集级模拟占位，链接支持新页面打开；配置和报告仍仅存于当前页面内存。

回归检查：`node --test tests/test-suites.test.cjs`。

## 研发知识资产

侧栏“资产”管理截图、办公文档、设计文件、PDF、视频、Demo 文件及外部链接，与系统构建的“制品管理”分开。支持搜索、类型/用途筛选、详情、下载、归档和恢复，不引入资产版本。同名文件也是独立资产，不覆盖旧文件。

需求开发的输入区支持上传资料、添加链接和引用已有资产；上传时自动关联当前需求。可以将资料限定到当前需求，或选择该需求对应产品供同产品其他需求复用。移除引用不删除资产，被引用的资产不能删除；归档保留历史引用但禁止新增引用。当前只有管理员演示身份，范围检查不是服务端安全权限控制。

上传每次最多 10 个文件、单个不超过 50 MB。文件仅保存在当前页面内存，刷新后清除，不上传外部服务、不提取内容、不调用 AI。图片和 PDF 可预览，其他文件只提供下载；程序、脚本和外部页面不会自动执行。PDF 使用本地打包的 Mozilla PDF.js 6.3.289 绘制页面，不使用外部 CDN；加密、损坏或不支持的文档显示下载提示。第三方许可见 `vendor/pdfjs/LICENSE`。

资产检查：`node --test tests/assets.test.cjs`。本地浏览器已验证需求多文件上传、草稿保留、截图/PDF 预览、链接校验、多需求引用与归档筛选。

# AI 自主决策提交，交付记录固定实际代码输入

第三轮架构访谈中，用户对提交范围选择“由 AI 自己决策”。不把原型的人工确认按钮作为必经步骤：执行 Agent 可以判断提交时机与范围，但提交必须有明确的代码内容、来源和理由。自主提交不包括合并主干、发布、扩仓库或改写历史。

共享工作区不能天然按会话分离代码。技术实现建议默认整体快照；局部提交则明确选中操作或补丁，在确定分支基线上生成完整 tree。其他会话后续修改不混入已经生成的提交、候选包或测试输入。数据库与 Git 分别持久化，必须用提交请求与引用对账处理故障，不假设跨系统事务。

相对于逐次人工审批，此选择减少反馈阻塞，但要求系统展示实际变更来源与开发验证，且由工具协议而非 AI 文本保证追溯。
